## 📁 Repository Structure

### [📂 LAB ASSIGNMENT 1](./LAB%20ASSIGNMENT%201)
**Project Title:** OTAKUVERSE — Cyberpunk Anime E-Commerce Storefront  
**Lab Assignment:** Building the Storefront (HTML5 + CSS3 + Vanilla JS)  
**Covers:** Project Phase 1 & Phase 2 Specifications (COER University Lab Sheet 1)

#### 📜 Folder Contents:
- **`LAB ASSIGNMENT 1/index.html`**: Home page introducing the store, hero section, canvas particle background, and featured product cards.
- **`LAB ASSIGNMENT 1/products.html`**: Complete catalog listing 19 products with an interactive category filter bar.
- **`LAB ASSIGNMENT 1/product-detail.html`**: Single product page with gallery thumbnail switcher, technical specifications, and quantity counter.
- **`LAB ASSIGNMENT 1/cart.html`**: Dynamic shopping cart table displaying line item subtotals, express shipping calculation, and grand total.
- **`LAB ASSIGNMENT 1/checkout.html`**: Checkout form with address input validation, radio payment options, order summary sidebar, and place order alert.
- **`LAB ASSIGNMENT 1/style.css`**: Central stylesheet with CSS custom properties (`:root`), Flexbox navbar, responsive CSS Grid cards, and mobile `@media` queries.
- **`LAB ASSIGNMENT 1/cart.js`**: Interactive shopping cart engine supporting `localStorage` persistence, `addToCartById`, item removal, quantity updates, and toast notifications.
- **`LAB ASSIGNMENT 1/products-data.js`**: 19-product dataset containing authentic Genshin Impact, Honkai: Star Rail, Lord of the Mysteries webnovels, action figures, keychains, and posters.
- **`LAB ASSIGNMENT 1/particles.js`**: Interactive HTML5 Canvas 2D floating sakura petals and glowing energy particles.
